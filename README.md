# CIS sistema

## Aprašymas

Šis projektas yra konkursų informacinė sistema (CIS), skirta mokykloms ir kitoms organizacijoms valdyti konkursus. Sistema leidžia registruoti dalyvius, kurti užduotis, vertinti darbus bei generuoti rezultatus.

## Projekto tikslas

Sukurti funkcionalią sistemą, kuri padėtų:
- Administruoti konkursus ir jų užduotis.
- Valdyti dalyvių registraciją.
- Kurti vertinimo kriterijus ir apskaičiuoti rezultatus.

## Instrukcijos, kaip paleisti

1. **Klonuokite repozitoriją**:

   ```bash
   git clone https://github.com/CIS-apprenticeship-project/web-app
   cd cis-app
   ```

2. **Įdiekite priklausomybes**:

   ```bash
   npm install
   ```

3. **Paleiskite projektą**:
   ```bash
   npm run dev
   ```
